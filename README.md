# My Portfolio

A portfolio made with **HTML, CSS & JavaScript**.

No React. No Next.js. No Vite. No 900MB `node_modules`.

Just:

```text
HTML → CSS → JavaScript → Ship it.
```

### Why HTML?

Because if a portfolio needs a framework, I probably need to rethink the portfolio.

Want a heading?

```html
<h1>Hello World</h1>
```

Want to deploy?

```bash
git push
```

No build errors.
No dependency conflicts.
No `npm install` trauma.

**HTML isn't outdated. We just keep adding problems to things that already work.**
